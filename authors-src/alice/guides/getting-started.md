1. Install Ruby 3.x and Bundler, then run `bundle install`.
2. Start the development server with `bundle exec jekyll serve` and open
   <http://localhost:4000>.
3. Edit `_config.yml`: set the site title, author, email and social links.
4. Replace the demo content in `authors-src/` with your own author folders.

Because this page has `order: 1` and the category has a root page with
`order: 0`, it gets previous/next links and a "Back to category" link.
