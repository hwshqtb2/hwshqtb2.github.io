**Jekyll Authors Template** is a small multi-author starter for Jekyll. It is
built for sites where several people contribute pages and posts, and where the
site owner keeps control of the category structure.

## What you get

- **Folder based authoring.** Each author owns a folder under `authors-src/`.
  Pages, posts, drafts and reusable includes are mirrored into the positions
  Jekyll expects before the build, so nothing special is needed in the author's
  front matter.
- **Category pages.** A page at the site root named after a category (for
  example `guides.md`) lists every page and post in that category. The list is
  generated by `_plugins/CategoryList.rb`.
- **Ordered chapters.** Give pages in a category an `order` value and add an
  `order: 0` overview page; `_plugins/CategoryOrder.rb` adds previous/next links, a
  back-to-category link and a nested table of contents.
- **Author pages.** A page with `categories: [author]` is an author profile; it
  is published under `/author/<title>.html`.
- **Tag pages, feed and sidebar.** `_plugins/TagsPage.rb`, `jekyll-feed` and
  `_plugins/Recent.rb` generate `/tags/<tag>.html`, `feed.xml` and the
  "Recently updated" sidebar.
- **License inheritance.** `_plugins/DefaultLicense.rb` lets pages in a category
  inherit the license of the category's root page.

## Where things live

| Path | Purpose |
| --- | --- |
| `authors-src/<author>/` | One folder per author (configurable via `authors.source`). |
| `<category>.md` | Category page at the site root; also the switch that enables that category. |
| `docs/` | Authoring and configuration guides (not published). |
| `_plugins/` | The small plugins that power the template. |
